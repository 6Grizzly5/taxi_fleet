# TaxiFleet  

**TaxiFleet** est une application web de gestion de flotte de taxis développée avec **Spring Boot**.

L’objectif du projet est de centraliser et simplifier la gestion d’une flotte de véhicules et des différents éléments qui lui sont associés. L’application permet notamment de gérer les **taxis, chauffeurs, utilisateurs et informations liées à la flotte**, tout en assurant un accès sécurisé aux différentes fonctionnalités.

Le projet met en œuvre plusieurs concepts du développement d’applications web avec **Java et Spring Boot**, notamment la gestion des utilisateurs et des rôles, l’authentification, la sécurité avec **Spring Security**, ainsi que l’architecture MVC et la persistance des données.

###  Technologies utilisées

- **Java**
- **Spring Boot**
- **Spring MVC**
- **Spring Security**
- **Spring Data JPA / Hibernate**
- **MySQL**
- **Thymeleaf**
- **Maven**
- **HTML / CSS**
- **Git & GitHub**

###  Objectifs

- Gérer efficacement une flotte de taxis
- Centraliser les informations sur les véhicules et les chauffeurs
- Sécuriser l’accès à l’application selon les rôles des utilisateurs
- Mettre en pratique les concepts de **Spring Boot** et du développement web Java
- Concevoir une application structurée, maintenable et évolutive

**TaxiFleet** constitue ainsi un projet académique permettant de mettre en pratique le développement d’une application web complète avec l’écosystème **Spring Boot**.
